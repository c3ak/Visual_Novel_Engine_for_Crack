첫 카트리지

배경 하나와 인물 하나를 넣어 크랙에서 띄워 보는 데까지입니다. 이 순서를 한 번 지나면 나머지 기능은 manifest 에 칸을 더하는 일입니다.

  1. 스튜디오 열기

    받은 vn-cartridge-studio.html 을 크롬이나 엣지로 열고 빈 카트리지로 시작 을 누릅니다. 이미 있는 .vncartridge 는 창에 끌어 놓으면 열립니다.

  2. 기본 정보 적기

    개요 탭 아래의 기본 정보 편집에서 이름·카트리지 ID·버전 등을 입력합니다. 입력은 자동 반영됩니다. 세부 설정은 파일 탭의 manifest.json에서도 편집할 수 있습니다.

    manifest.json
    {
  "format": "vn-engine-cartridge",
  "formatVersion": 1,
  "id": "myname.teahouse-story",
  "name": "골목 끝 찻집",
  "version": "1.0.0",
  "engineVersion": "4.0.0",
  "author": "내 이름",
  "description": "찻집 주인 미라와의 이야기",
  "storyIds": [],
  "presentation": { "animations": [], "bgm": [], "opening": [] },
  "modules": [],
  "assets": {}
}
    • id 는 플레이어 저장 값의 열쇠입니다. 한 번 배포하면 바꾸지 않습니다. 내이름.작품이름 꼴을 권합니다.
    • engineVersion 은 "4.0.0" 그대로 둡니다. 스튜디오가 새 카트리지에 미리 적어 둡니다.
    • storyIds 는 비워 두고 시작합니다. 비어 있으면 어느 작품에서나 손으로 적용됩니다. 배포할 때 채웁니다(배포).

  3. 그림 넣기

    미디어 탭의 미디어 추가 를 누르거나 파일을 끌어 놓습니다. 확장자를 뗀 파일 이름이 곧 부르는 이름입니다. 배경은 bg_ 로 시작하게, 인물은 영문 + 번호 로 짓습니다(그림 규칙).

    bg_teahouse.webp → ![bg_teahouse] · mira01.webp → ![mira01]

  4. 이미지 코드를 프롬프트에 넣기

    미디어 탭의 이미지 코드 전체 복사 를 누르면 ![bg_teahouse] 같은 줄이 모두 복사됩니다. 이것을 크랙 작품 프롬프트의 그림 목록에 붙이고, 그림마다 언제 쓰는지 한마디씩 적습니다(작품 프롬프트).

  5. 내보내기

    위쪽 내보내기 를 누릅니다. 스튜디오는 엔진과 같은 판독기로 검사하므로, 내보내지면 엔진도 받습니다. 걸리면 무엇이 틀렸는지 알려 줍니다.

    보호 와 편집용 원본도 저장 이 켜져 있으면(기본) 파일 두 개가 저장됩니다. <id>.vncartridge 는 압축 프로그램으로 열리지 않는 배포용 보호 파일, <id>.source.vncartridge 는 편집용 원본입니다. 보호 파일은 스튜디오로 다시 열 수 없으니 원본을 꼭 보관합니다.

  6. 크랙에서 적용하고 보기

    크랙 채팅방 왼쪽 아래 설정 → 📚 라이브러리 에 파일을 끌어 놓고 확인. UI 테스트 로 그림과 메뉴가 나오는지 보고, VN 시작 으로 실제 응답을 받아 봅니다.

고친 뒤에는 스튜디오에서 .source.vncartridge 를 열어 고치고, version 을 올려 다시 내보낸 뒤 라이브러리에 다시 넣습니다. 같은 id 면 새 파일로 바뀝니다.

## 상태창
응답 맨 끝에 아래 블록을 붙인다. 첫 줄의 칸 순서는 바꾸지 않는다.
```
T-1｜2025년 05월 15일｜목요일｜21:40｜밤｜🌧️｜찻집 - 카운터
[소지품｜12 금화, 녹슨 열쇠]
[관계]
미라 - 호감도 38
[상황｜비를 피해 찻집에 들어왔다]
```
  • 그림마다 설명(평소 · 웃음 · 놀람)을 붙여야 AI 가 표정을 골라 씁니다. 목록은 프롬프트 글자 수를 차지하니 실제로 쓰는 그림만 넣습니다.
  • 상태창 첫 줄은 ｜ 로 나눈 차례 번호 · 날짜 · 요일 · 시각 · 시간대 · 날씨 · 위치 입니다. 차례 번호(T-1)는 화면에 나오지 않고, 나머지는 화면 위 정보 바에 뜹니다.
  • [항목｜값] 이나 [항목] + 다음 줄들은 메뉴 탭이 됩니다. 소속 · 관계 · 소지품 · 상황 · 일정은 늘 보이고, 그 밖의 이름은 내용이 있을 때 AI 가 쓴 순서대로 붙습니다.
  • 호감도나 돈 같은 수치는 상태창 항목으로 쓰게 하면 메뉴에서 보이고, 장면 조건과 모듈에서도 읽을 수 있습니다.

그림 규칙

패키지에 넣은 그림(png jpg webp avif gif bmp svg)은 manifest 에 적지 않아도 모두 이름이 붙습니다. 이름은 확장자를 뗀 파일 이름입니다.

  • 정확히 같아야 합니다. 앞뒤 공백과 영문 대소문자만 무시하고, 부분 일치는 없습니다. ![mira] 는 mira01 을 찾지 못합니다.
  • 폴더는 이름에 들어가지 않습니다. 다른 폴더에 같은 이름이 있으면 하나만 남으니 겹치지 않게 짓습니다.

배경인가 인물인가

위에서부터 처음 맞는 것으로 정합니다. 배경은 bg_ 접두사가 가장 안전합니다. 폴더 규칙(/g/ /c/)은 플레이어 설정으로 바뀔 수 있습니다.

조건판정예
이미지 표에 kind 를 적음적은 대로"kind": "background"
파일 이름이 bg_ 로 시작배경bg_teahouse.webp
경로에 /g/배경assets/g/sky.webp
경로에 /c/인물assets/c/mira01.webp
아무 신호 없음인물mira01.webp

같은 인물로 묶기

이름 끝의 번호를 뗀 값이 인물 ID 입니다. 같은 인물 ID 의 그림이 오면 새로 세우지 않고 표정만 바꿉니다.

그림 이름인물 ID결과
mira01 mira02mira같은 인물, 표정만 바뀜
yuna_01yuna밑줄 뒤 번호도 뗌
yuna_smileyuna_smile번호가 없어 이름 전체가 ID
미라01미라01영문이 아니면 장마다 다른 인물로 나란히 섬

한글 이름을 쓰고 싶으면 아래 이미지 표에 characterId 를 적습니다.

이미지 표

이름과 그림을 직접 짝지을 때 씁니다. 파일 색인보다 먼저 봅니다. 외부 주소(https://)도 됩니다.

manifest.json · assets
"assets": {
  "images": {
    "찻집": "assets/g/bg_teahouse.webp",
    "미라": { "path": "assets/c/mira01.webp", "kind": "character", "characterId": "mira" },
    "골목": { "url": "https://cdn.example.com/x7Kp2.png", "kind": "background" }
  }
}
  • 인물 항목의 키는 화자 이름으로도 쓰입니다. "**미라** | …" 대사가 나오면 인물 mira 를 밝게, 나머지를 어둡게 합니다.
  • 외부 주소에도 같은 판정이 걸립니다. 주소에 /g/ 가 없는 배경은 "kind": "background", 파일 이름이 무작위인 인물은 characterId 를 꼭 적습니다.

화면에서의 동작

가로로 긴 인물 그림

가로 ÷ 세로가 1.2 보다 크면 스탠딩이 아니라 화면 전체를 덮는 이벤트 CG 로 뜹니다. 같은 인물의 세로 그림이 오거나 퇴장하면 내려갑니다.

퇴장

--- 장면 경계에서 그림이 안 나온 인물은 퇴장합니다. 직접 내보내려면 ![mira](off). 한글 ID 는 퇴장이 아니라 글자로 찍힙니다.

크기

카트리지는 압축하지 않아 그림 크기가 그대로 파일 크기입니다. 인물은 높이 1100px, 배경은 폭 1920px 의 WebP(품질 82~85)를 권합니다.

연출

오프닝과 장면은 AI 응답과 같은 문법으로 쓰는 미리 쓴 대본입니다. 모두 manifest.json 의 presentation 안에 둡니다.

오프닝

스튜디오의 오프닝 탭에서 추가한 뒤 제목과 대본을 적습니다. 그림 선택으로 이미지 코드를 넣고, 간단 미리보기로 그림과 대사 순서를 확인할 수 있습니다. 음악과 애니메이션을 포함한 전체 연출은 실제 엔진에서도 확인합니다.

채팅방에서 VN 을 처음 켤 때 한 번 재생합니다. 두 개 이상이면 시작할 때 고르는 창이 뜹니다.

presentation.opening
"opening": [
  { "title": "도착", "content": "![bg_teahouse]\n*문에 달린 종이 맑게 울렸다.*\n![mira01]\n\"**미라** | 어서 오세요. 오늘은 첫 손님이네요.\"" }
]

주의 오프닝 content 는 문자열 하나만 됩니다. 줄바꿈은 \n. 줄 배열로 주면 카트리지 적용이 멈출 수 있습니다.

이야기 도중 끼워 넣는 장면

AI 응답이 조건에 맞으면 미리 쓴 장면을 그 자리에 끼워 넣습니다. 적은 조건이 모두 맞아야 틉니다.

presentation.scenes
"scenes": [
  {
    "id": "old-letter",
    "title": "오래된 편지",
    "when": { "text": "편지", "in": ["dialogue", "narration"] },
    "repeat": "once",
    "tellAi": "카운터 밑에서 누렇게 바랜 편지를 발견했다.",
    "content": ["*봉투 하나가 미끄러져 나왔다.*", "![mira03]"]
  }
]
조건값맞는 때
text글자 또는 배열응답에 그 글자가 있으면. 배열이면 하나라도
inall dialogue narration status hiddentext 를 찾을 범위. text 와 함께만
date{ "on": "2025년 05월 15일" } · { "from": … }상태창 날짜가 그날 / 그날부터
location weather글자 또는 배열상태창 값에 그 글자가 들어 있으면
time dayPeriod weekday글자 또는 배열상태창 값과 같으면
section{ "소지품": "열쇠" }상태창 그 항목에 그 글자가 있으면
  • 표에 없는 조건 이름이 하나라도 있으면 장면을 통째로 버립니다. 오타를 조심합니다.
  • repeat: once 채팅방마다 한 번(기본), every 맞을 때마다.
  • 글자 조건이 있으면 그 글자가 처음 나온 줄 바로 뒤에 틀고, 없거나 "play": "after" 면 응답이 끝난 뒤에 틉니다.
  • tellAi 를 적어야 AI 가 그 장면이 있었다는 걸 압니다. 플레이어의 다음 메시지에 붙어 나갑니다.
  • AI 가 장면 신호를 확실히 내게 하려면, 프롬프트에 숨은 줄 [//]: # (편지) 를 쓰라고 적고 "in": "hidden" 으로 잡습니다.

애니메이션 · BGM

그림 이름에 trigger 글자가 들어 있으면 걸립니다.

누르는 자리 · 방 화면

배경 위에 누를 수 있는 자리를 두거나, 대화하지 않을 때 머무는 방 화면을 만듭니다. 둘 다 그림 위 위치를 rect 로 적습니다.

위치 적는 법 rect

[왼쪽, 위, 너비, 높이] 를 그림 크기에 대한 0~1 비율로 적습니다. 픽셀 값을 그림의 가로 · 세로로 나누면 됩니다. 화면에서 배경이 잘려 보여도 엔진이 맞춥니다.

1920 × 1080 그림에서 왼쪽 880 · 위 76 에 있는 250 × 594 크기 괘종시계 → [0.458, 0.07, 0.13, 0.55]

배경 위 누르는 자리 hotspots

manifest.json · hotspots
"hotspots": {
  "reveal": "hover",
  "areas": {
    "bg_teahouse": [
      { "id": "menu-board", "rect": [0.06, 0.12, 0.2, 0.36], "image": "menu_board", "label": "오늘의 메뉴판",
        "tellAi": { "title": "메뉴판", "text": "벽에 걸린 메뉴판을 들여다봤다." } }

  • areas 의 키는 배경 그림의 부르는 이름입니다(파일 경로가 아님). 그 배경이 떠 있을 때만 자리가 생깁니다.
  • image 는 눌렀을 때 띄울 그림 이름, label 은 그 아래 이름표입니다.
  • reveal: always 늘 은은한 테두리 · hover 마우스를 올리면 · hidden 표시 없음.
  • 누르면 엔진은 그림을 띄우고 tellAi 를 대기열에 넣을 뿐입니다. 아이템을 얻거나 화면을 여는 일은 상시 모듈 코드가 hotspot 신호를 받아 합니다.

방 화면 home

대화하지 않을 때 머무는 기본 화면입니다. 캐릭터를 누르면 선택지가 뜨고, 대화하기 를 고르면 대사창이 있는 대화 화면으로 넘어갑니다. 대화 종료 로 돌아옵니다.

manifest.json · home

모듈

지도, 도감, 미니게임처럼 작품만의 화면은 HTML · CSS · JS 모듈로 만듭니다. 엔진은 “일이 일어났다” 고 알리고, 엔진만 할 수 있는 일을 부탁받아 해 줄 뿐입니다. 무엇을 얻고 언제 무엇을 여는지 같은 규칙은 모듈 코드에 둡니다.

종류

종류정의동작
화면"type": "view"메뉴 탭에서 열 때만 존재합니다. 닫으면 코드가 멈춥니다.
상시"type": "service"카트리지가 켜진 동안 보이지 않게 늘 돕니다. 규칙과 상태는 여기 둡니다.

예: 라디오를 누르면 연출을 틀고 AI 에게 알리기

늘 받아야 하는 신호는 상시 모듈에서 받습니다. 화면 모듈은 닫혀 있으면 신호를 받지 못합니다.

modules/keeper/index.js · 상시 모듈
VNCartridge.on('hotspot', async spot => {
  if (spot.id !== 'old-radio') return;
  const result = await VNCartridge.playScript([
    '![screen](black 1s wait)',
    '![bg_radio_room]',
    '![screen](clear 1s wait)',
    '*낡은 라디오에서 잡음이 흘러나왔다.*'
  ], { id: 'radio' });
  if (!result.ok) return;   // 다른 응답이 끼어들었거나 VN 을 껐다
  VNCartridge.shared.patch({ radioHeard: true });
  VNCartridge.tellAi('라디오', '주인공이 낡은 라디오를 켜 잡음을 들었다.', { id: 'radio', replace: true });
});

값의 주인을 하나로

AI 가 상태창에 쓰는 값(위치, 시각, 돈, 호감도)은 모듈이 읽기만 합니다. 모듈이 맡은 값은 모듈만 고칩니다. 둘이 같은 값을 고치면 어긋납니다. 모듈이 무언가를 바꿨으면 tellAi 로 알려 AI 가 상태창에 반영하게 합니다.

한도값
공유 서랍 · 모듈 저장 값각각 JSON 250,000자

AI 알림 대기열50개. 넘으면 오래된 것부터 빠집니다. 바뀌는 알림은 같은 id + replace: true

꾸미기

색과 글꼴만 바꾸려면 테마, 모양까지 바꾸려면 스킨을 씁니다. 플레이어는 Ctrl + Alt + T 로 외형을 끌 수 있으니, 외형 없이도 읽히는 카트리지로 만듭니다.

테마 theme

  • 메뉴 버튼과 창 닫기 버튼은 숨길 수 없습니다.

AI 에게 맡기기

manifest 와 모듈 코드는 ChatGPT · Claude 에게 맡겨도 됩니다. 명세서를 함께 주면 엔진이 받지 않는 칸을 지어내지 않습니다.

  1. 파일 첨부

    대화에 cartridge-spec-for-ai.md 를 첨부합니다. 고칠 카트리지가 있으면 그 manifest.json 내용도 붙입니다.

  2. 요청

    아래 틀을 채워 보냅니다.

  3. 스튜디오에 붙이기

    받은 파일을 스튜디오 파일 탭에서 같은 경로로 만들거나 고쳐 저장하고 내보내기. 검사에 걸리면 그 오류 문구를 그대로 AI 에게 돌려줍니다.

AI 에게 보내는 요청 틀
첨부한 명세서(cartridge-spec-for-ai.md)대로 VN 엔진 카트리지 작업을 해 줘.

- 하려는 것: (예: 찻집 배경의 장부를 누르면 장부 화면이 메뉴에 생기고 열린다)
- 지금 카트리지: (manifest.json 내용, 없으면 "새로 만든다")
- 그림 이름: (예: bg_teahouse, bg_street, mira01~03, menu_board)
- 누르는 자리 좌표: (그림 크기와 픽셀 위치, 또는 비율)

명세서에 없는 칸이나 함수는 쓰지 말고, 정해지지 않은 값은 지어내지 말고 물어봐.

출시 전 확인

작품 소개에 적을 것

  • 카트리지 파일 받는 곳과 버전
  • 엔진 설치 안내: 플레이 안내 페이지 링크
  • VN 엔진 4.0 이 필요하다는 안내
  • 입력창 명령이 있으면 그 목록(예: \지도)

문제가 생기면

엔진은 큰 잘못이면 카트리지를 거부하고, 작은 잘못이면 그 항목만 버린 뒤 콘솔(F12)에 VN Engine: 경고를 남깁니다. 먼저 콘솔을 봅니다.

카트리지를 넣으면 거부돼요
  • 스튜디오로 보호 파일을 열려고 했습니다. 편집은 .source.vncartridge 로 합니다.
  • 루트에 manifest.json 이 없거나 JSON 이 깨졌습니다. 주석과 끝 쉼표는 JSON 에서 쓸 수 없습니다.
  • 플레이어 엔진이 4.0 이 아닙니다. 그 전 엔진은 보호 파일과 4.0 카트리지를 받지 못합니다.
  • id · name 이 비었거나, 모듈 id 가 겹칩니다.
  • 모듈이 가리키는 파일(entry · scripts · images …)이 패키지에 없습니다. 경로는 대소문자를 가립니다.
그림이 안 떠요
  • 응답 원문에 ![…] 줄이 있는지 크랙 화면에서 봅니다. 없으면 프롬프트 문제입니다.
  • 줄의 이름과 파일 이름(확장자 뗀 것)이 정확히 같은지 봅니다. ![mira] 는 mira01 을 찾지 못합니다.
  • 플레이어 설정이 비주얼챗 모드인지 봅니다.
같은 인물이 여러 명으로 나란히 서요

인물 ID 가 그림마다 다릅니다. 영문 + 번호로 짓거나(mira01 mira02), 이미지 표에 같은 characterId 를 적습니다.

인물 그림이 화면 전체를 덮어요

가로 ÷ 세로가 1.2 를 넘어 이벤트 CG 로 판정됐습니다. 스탠딩은 세로형으로 자릅니다.

배경이 인물처럼 떠요

배경 신호가 없습니다. 파일 이름을 bg_ 로 시작하게 하거나, 외부 주소면 이미지 표에 "kind": "background" 를 적습니다.

장면이 안 나와요
  • when 에 표에 없는 조건 이름이 있으면 장면이 통째로 버려집니다.
  • "repeat": "once" 장면은 채팅방마다 한 번입니다. 새 채팅방에서 시험합니다.
  • 날짜 조건은 상태창 날짜가 년 월 일 이 있는 같은 꼴이어야 합니다.
모듈 화면이 비어 있어요
  • localStorage, <img src="assets/…">, parent.document 는 격리 액자에서 오류가 납니다. 대신 쓸 것을 봅니다.
  • entry HTML 의 <script src> 는 파일을 못 찾습니다. scripts 배열에 적습니다.
업데이트했더니 플레이어 저장 값이 사라졌어요

카트리지나 모듈의 id 가 바뀌었습니다. id 는 저장소 열쇠라 처음 값으로 되돌리면 다시 보입니다.

같은 알림이 AI 에게 여러 번 가요

바뀌는 알림을 매번 새 tellAi 로 넣었습니다. 같은 id 에 replace: true 를 주면 하나만 남습니다.
